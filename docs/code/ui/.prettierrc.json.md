# [`ui/.prettierrc.json`](../../../ui/.prettierrc.json)

## Purpose

The Prettier configuration for the UI. It changes two defaults; every other option keeps Prettier's default.

## Public API

| Key           | Type    | Value  | Purpose                                     |
| ------------- | ------- | ------ | ------------------------------------------- |
| `singleQuote` | boolean | `true` | Single quotes in TypeScript and JavaScript. |
| `printWidth`  | number  | `100`  | Wraps lines longer than 100 columns.        |

## Details

Not applicable: neither setting affects security.

## Dependencies

- **Internal**: [`.prettierignore`](.prettierignore.md) chooses which files Prettier skips.
- **External**: `prettier`.

## Used by

- `npm run format` and `npm run format:check`, see [`package.json`](package.json.md).
- [`eslint.config.js`](eslint.config.js.md), which turns off the ESLint rules that would conflict with this formatting.

## Tests

Not applicable: configuration file. CI fails on unformatted files through `npm run format:check`.

## Notes

- Prettier runs from `ui/`, so this configuration covers only the UI. Files outside `ui/`, `docs/` included, are not format-checked.
