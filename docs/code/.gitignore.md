# [`.gitignore`](../../.gitignore)

## Purpose

Lists the files Git must never track: build output, dependencies, generated Tauri files, environment files and keys, vault files, and OS and editor clutter. It enforces the project rule "never commit secrets, vault files, build artifacts, `node_modules/` or `target/`" from [`CLAUDE.md`](../../CLAUDE.md).

## Public API

### Rust

| Pattern       | Ignores                                                    |
| ------------- | ---------------------------------------------------------- |
| `target/`     | Cargo build output, at any depth (the workspace's root `target/`). |
| `**/*.rs.bk`  | Backup files left by older `rustfmt` versions.             |
| `*.pdb`       | Windows debug symbol files.                                |

`Cargo.lock` is deliberately not ignored (comment: "NovaVault ships a binary").

### Node / frontend

| Pattern                                                             | Ignores                                      |
| ------------------------------------------------------------------- | -------------------------------------------- |
| `node_modules/`                                                     | npm dependencies (root and `ui/`).           |
| `dist/`, `dist-ssr/`                                                | Vite build output, including `ui/dist`.      |
| `.vite/`                                                            | Vite cache.                                  |
| `coverage/`                                                         | Test coverage reports.                       |
| `.pnpm-store/`                                                      | pnpm store.                                  |
| `*.tsbuildinfo`                                                     | TypeScript incremental build state (`tsc -b`). |
| `*.log`, `npm-debug.log*`, `yarn-debug.log*`, `yarn-error.log*`, `pnpm-debug.log*` | Log files.                    |

### Tauri

| Pattern                                 | Ignores                                                                     |
| --------------------------------------- | --------------------------------------------------------------------------- |
| `src-tauri/target/`                     | A crate-local build directory.                                              |
| `src-tauri/gen/schemas/`                | JSON schemas generated by `tauri-build`.                                    |
| `src-tauri/permissions/autogenerated/`  | Per-command permission files regenerated by [`build.rs`](src-tauri/build.rs.md) on every build. |
| `src-tauri/WixTools/`                   | WiX toolset downloaded for Windows MSI bundling.                            |

### Environment and secrets

| Pattern          | Ignores                                                     |
| ---------------- | ----------------------------------------------------------- |
| `.env`, `.env.*` | Environment files, at any depth.                            |
| `!.env.example`  | Re-includes an example file, which must contain no real values. |
| `*.pem`, `*.key`, `*.p12`, `*.pfx` | Certificates and private keys (for example code-signing keys). |

### Vault files

| Pattern        | Ignores                                       |
| -------------- | --------------------------------------------- |
| `*.novavault`  | Vault files under a long extension.           |
| `*.nvault`     | Vault files: the app's file name is `vault.nvault`. |
| `*.vault`, `*.vault.bak` | Other vault-like files and backups. |
| `vault/`       | Any directory named `vault`.                  |

### OS and editors

| Pattern                                                    | Ignores                                       |
| ---------------------------------------------------------- | --------------------------------------------- |
| `.DS_Store`, `._*`                                         | macOS Finder metadata and resource forks.     |
| `Thumbs.db`, `ehthumbs.db`, `desktop.ini`, `$RECYCLE.BIN/` | Windows Explorer files.                       |
| `.idea/`, `*.iml`                                          | JetBrains IDEs.                               |
| `.vscode/*`, `!.vscode/extensions.json`, `!.vscode/settings.json` | VS Code, except shared recommendations and settings. |
| `*.swp`, `*.swo`, `*~`                                     | Vim swap files and editor backups.            |
| `*.sublime-project`, `*.sublime-workspace`                 | Sublime Text.                                 |

## Details

### Security-relevant patterns

- **Vault files.** A vault holds a user's encrypted data and its key slots. Even encrypted, it must not be published: it would expose the data to offline guessing of the master password. `*.nvault` covers the real file name used by the shell ([`main.rs`](src-tauri/src/main.rs.md), `vault.nvault`). The attachment directory `vault.nvault.attachments/` is not matched by `*.nvault` (a directory name ending in `.attachments`), but it only exists in the app data directory, outside the repository.
- **Keys and environment files.** `*.pem`, `*.key`, `*.p12`, `*.pfx` and `.env*` stop signing keys, certificates and tokens from being committed by accident, for example when release signing is set up.
- **Generated Tauri files.** `src-tauri/permissions/autogenerated/` and `src-tauri/gen/schemas/` are regenerated from [`build.rs`](src-tauri/build.rs.md) and `tauri.conf.json` on each build, so the committed capability file ([`default.json`](src-tauri/capabilities/default.json.md)) is the single reviewed source of permissions.
- **Ignore is not protection.** `.gitignore` does not affect files already tracked and can be bypassed with `git add -f`. Review remains the guard.

### Pattern semantics

Patterns without a `/` other than a trailing one (`target/`, `dist/`, `*.nvault`) match at any depth. Patterns containing a `/` (`src-tauri/gen/schemas/`) are relative to the repository root. A trailing `/` matches directories only. A `!` line re-includes a file that an earlier pattern excluded, which works only if its parent directory is not itself excluded; `.vscode/*` (contents, not the directory) makes the `.vscode` exceptions possible.

## Dependencies

- **Internal**: none.
- **External**: Git.

## Used by

- Git, for `git status`, `git add` and every other command that lists untracked files.
- Prettier and ESLint do not read it: the UI has its own [`ui/.prettierignore`](ui/.prettierignore.md) and ESLint ignores `dist` and `coverage` in [`ui/eslint.config.js`](ui/eslint.config.js.md).

## Tests

_Not applicable: a configuration file has no tests. `git check-ignore -v <path>` shows which line ignores a path._

## Notes

- `src-tauri/target/` is redundant: `target/` already matches at any depth. It does no harm.
- `*.novavault`, `*.vault` and `*.vault.bak` are broader than the app needs; the app only writes `*.nvault`. `vault/` would also ignore any future source directory named `vault`.
- `.pnpm-store/`, the Yarn and pnpm log patterns are unused: the project uses npm.
- The `.vscode` exceptions are forward-looking: there is no `.vscode/` directory in the repository.
