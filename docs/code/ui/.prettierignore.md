# [`ui/.prettierignore`](../../../ui/.prettierignore)

## Purpose

Lists the paths under `ui/` that Prettier skips when formatting or checking.

## Public API

| Entry               | Purpose                 |
| ------------------- | ----------------------- |
| `dist`              | Vite build output.      |
| `coverage`          | Test coverage output.   |
| `node_modules`      | Installed dependencies. |
| `package-lock.json` | Generated by npm.       |

## Details

Not applicable: no entry affects security. Prettier skips `node_modules` by default; listing it just makes that explicit.

## Dependencies

- **Internal**: complements [`.prettierrc.json`](.prettierrc.json.md).
- **External**: `prettier`.

## Used by

- `npm run format` and `npm run format:check`, see [`package.json`](package.json.md).

## Tests

Not applicable: configuration file.

## Notes

- [`eslint.config.js`](eslint.config.js.md) ignores the same `dist` and `coverage` paths.
