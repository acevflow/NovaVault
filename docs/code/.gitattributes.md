# [`.gitattributes`](../../.gitattributes)

## Purpose

Tells Git how to treat files: which are text and with which line endings, which are binary, and which lockfiles are generated. It keeps the repository byte-identical across Windows, macOS and Linux checkouts and matches the editor settings in [`.editorconfig`](.editorconfig.md).

## Public API

### Line endings

| Pattern                   | Attributes            | Effect                                                                             |
| ------------------------- | --------------------- | ---------------------------------------------------------------------------------- |
| `*`                       | `text=auto eol=lf`    | Git detects text files, stores them with LF and checks them out with LF on every OS. |
| `*.bat`, `*.cmd`, `*.ps1` | `text eol=crlf`       | Always text, checked out with CRLF (Windows scripts require it).                   |
| `*.svg`                   | `text`                | Always text (SVG is XML), so it is diffed and normalized; LF from the `*` rule.    |

### Binary assets

| Pattern                                                    | Attributes | Effect                                                         |
| ---------------------------------------------------------- | ---------- | -------------------------------------------------------------- |
| `*.png`, `*.jpg`, `*.jpeg`, `*.gif`, `*.ico`, `*.icns`     | `binary`   | Images: no line-ending conversion, no text diff, no text merge. |
| `*.woff`, `*.woff2`, `*.ttf`, `*.otf`                      | `binary`   | Fonts: same.                                                   |
| `*.pdf`                                                    | `binary`   | PDFs: same.                                                    |

`binary` is Git's macro for `-diff -merge -text`.

### Generated lockfiles

| Pattern             | Attributes                     | Effect                                                                 |
| ------------------- | ------------------------------ | ---------------------------------------------------------------------- |
| `Cargo.lock`        | `-diff linguist-generated`     | `git diff` shows only "Binary files differ"; GitHub collapses it in pull requests and excludes it from language statistics. |
| `package-lock.json` | `-diff linguist-generated`     | Same, for both the root and `ui/` lockfiles (a pattern without `/` matches at any depth). |
| `pnpm-lock.yaml`    | `-diff linguist-generated`     | Same, if one is ever added.                                            |
| `yarn.lock`         | `-diff linguist-generated`     | Same, if one is ever added.                                            |

## Details

### How the rules combine

Git applies every matching line, with later lines overriding earlier ones for the same attribute. For example, `src-tauri/icons/icon.ico` gets `binary` (which unsets `text`) from its own line, while `eol=lf` from the `*` line has no effect because the file is not text. `Cargo.lock` keeps `text=auto eol=lf` and adds `-diff linguist-generated`.

### Normalization

`text=auto eol=lf` means a contributor on Windows with `core.autocrlf` set still gets LF files in the working tree, which matches `.editorconfig` and keeps formatters (Prettier, rustfmt) from reporting line-ending changes.

### Security notes

- **Lockfile diffs are hidden locally and collapsed on GitHub.** `-diff` makes `git diff` and `git log -p` print "Binary files differ" for lockfiles, and `linguist-generated` collapses them in pull request reviews. This keeps reviews readable, but a lockfile change still needs a deliberate look: dependency updates (for example from [Dependabot](.github/dependabot.yml.md)) change exactly these files. Use `git diff --text Cargo.lock` or expand the file on GitHub to review them.
- `-diff` does not affect what is stored or built; `--locked` in CI still enforces the exact committed versions.

## Dependencies

- **Internal**: none.
- **External**: Git; GitHub Linguist for `linguist-generated`.

## Used by

- Git on every checkout, commit and diff.
- GitHub, for pull request diffs and the repository's language statistics.

## Tests

_Not applicable: a configuration file has no tests. `git check-attr -a -- <path>` shows the attributes a path receives._

## Notes

- `pnpm-lock.yaml` and `yarn.lock` are listed although the project uses npm only; the lines are harmless but unused.
- `.bat`, `.cmd` and `.ps1` rules are forward-looking: no such file is tracked today.
- Vault files (`*.nvault`) have no attribute because they must never be committed; [`.gitignore`](.gitignore.md) excludes them.
- `*.webp`, `*.avif` and other binary formats not listed rely on Git's `text=auto` detection, which treats files containing NUL bytes as binary.
