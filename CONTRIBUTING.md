# Contributing to NovaVault

Thank you for your interest in contributing to NovaVault! 🤝

NovaVault is an open-source project, and contributions of all kinds are welcome. You don't need to be an expert to help.

## 💡 Ways to Contribute

There are many ways you can contribute:

* 🐛 Report bugs
* 💡 Suggest new features
* 📖 Improve documentation
* 🎨 Improve the user interface
* 🧪 Add or improve tests
* 💻 Submit code
* 🔍 Review pull requests

## 🚀 Getting Started

1. Fork the repository.
2. Clone your fork.
3. Create a new branch for your changes.
4. Make your changes.
5. Test your changes.
6. Commit your work with a clear commit message.
7. Open a pull request.

Try to keep each pull request focused on one change whenever possible.

## 🔐 Security

Because NovaVault handles sensitive data, security-related changes require extra care.

**Never submit real passwords, private keys, personal documents, or other sensitive information to the repository.**

If you discover a security vulnerability, please report it privately instead of opening a public issue. See [SECURITY.md](SECURITY.md).

## 📝 Commit Messages

Please use clear and descriptive commit messages.

For example:

```text
feat: add password generator
fix: prevent vault lock timeout issue
docs: improve installation guide
refactor: simplify file storage service
```

## 📋 Pull Requests

When opening a pull request, please explain:

* What was changed.
* Why the change was needed.
* How it was tested.
* Any limitations or known issues.

Please make sure the project builds and tests pass before submitting your pull request.

## 🤝 Code of Conduct

By participating in this project, you agree to follow the rules described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Thank you for helping make NovaVault better! ❤️
